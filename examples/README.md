# Ejemplos

Archivos generados por el asistente, solo para ver la salida. **No los importes tal cual**: las interfaces, IP y subredes son de ejemplo.

- `ejemplo-2wan-balanceo.rsc` — dos líneas DHCP con balanceo PCC y failover recursivo
- `ejemplo-solo-balanceador.rsc` — modo WISP: este equipo solo reparte, delante de otro router
- `ejemplo-router-de-abajo.rsc` — lo que se aplica al router de abajo en ese montaje
- `ejemplo-desinstalador.rsc` — revierte todo lo que pone LBW

Genera los tuyos con `./lbw-wizard.sh`.
